## What WP11.4 added

One new test file, `tests/test_stage11_wp11_4_end_to_end_journeys.py`,
reusing WP11.3's disposable-Postgres fixture infrastructure
(`stage11_database`, `_client`, `_login`) rather than building a fourth
parallel harness:

- `test_personal_session_can_browse_the_public_catalog_and_favourite_a_symbol`
  — a zero-membership personal session logs in, browses the public Catalog,
  fetches a symbol's detail, favourites it, and sees it in their own
  favourites list — one continuous flow through the real routes, which no
  prior stage's test chained together for a personal (not organization)
  session specifically.
