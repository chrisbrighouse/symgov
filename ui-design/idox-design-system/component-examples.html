21. Callout panels

Use to surface contextual information, warnings, or errors inline within a form or page. Span full width when used inside a two-column grid.

Success heading

Use to confirm that an action has completed successfully or that a condition has been met.

Informational heading

Use for helpful guidance or contextual notes that do not require immediate action from the user.

Warning heading

Use when the user should be aware of a potential issue or upcoming action that may affect the system.

Error heading

Use when a critical error has occurred that prevents the user from proceeding or requires immediate attention.

27. Empty state

Use when a list, table, or panel has no content to display. Centre an icon, a short heading, a supporting sentence, and an optional call-to-action. The icon should use text-tertiary and a large size to create visual breathing room without competing with surrounding content.

32. Stat cards

KPI summary tiles for dashboards and case-list headers. Each card pairs a semantic icon badge with a large count, a short label, and a supporting subtitle. Use the four semantic variants (error, warning, info, neutral) to reinforce status meaning through colour.

33. Toast notification

Short, auto-dismissing messages for feedback on completed actions. Toasts appear bottom-right, stack upward, and dismiss after four seconds or on manual close. The showToast(message, type) helper accepts success, info, warning, and error variants.
